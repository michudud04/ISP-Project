---
name: replanning
description: How to propose a re-plan for a late task without breaking a course milestone.
---
Order of preference:
1. Cut scope of the late task (keep the milestone date). State what is cut.
2. Split the task: the part needed for the next milestone first.
3. Move the task date, only if no milestone depends on it.
Course milestones (never move): W3 design review, W4 video + pitch, W5 progress checkpoint, W6 final preparation, W7 final presentation.
